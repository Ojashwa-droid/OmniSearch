# The GATE Grind — design reference

This folder records design patterns observed on [thegategrind.online](https://thegategrind.online/) for possible future use in OmniSearch. It is a reference, not a redesign brief. Keep OmniSearch's newsroom identity and use only the selected patterns described in [omnisearch-adaptation.md](omnisearch-adaptation.md).

**Reviewed:** 2026-11-02  
**Reference:** https://thegategrind.online/  
**Scope:** visual system, interaction patterns, and accessibility considerations. No site assets or copy are reproduced here.

## Evidence standard

Visual descriptions in this pack come from viewing the live public site. Exact CSS values, font family names, animation timings, and breakpoint values have not been verified from the site's source styles; they are marked as unknown or approximate. Do not treat a visual estimate as a measured design token.

The site is a GATE exam preparation product. Its brand, wording, logo, illustrations, and educational content belong to that product and should not be copied into OmniSearch.
